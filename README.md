# Zoumourda BAC 2026 — invitation web

Site d'invitation inspiré du modèle Canva.

## Informations intégrées

- Date : 12 septembre 2026
- Heure : 15:00
- Lieu : Salle des fêtes Lala Meriem, Annaba
- Localisation : le bouton ouvre le lien Google Maps fourni.

## Fichiers

- `index.html` : structure du site
- `style.css` : design, responsive et animations
- `script.js` : animation d'apparition et navigation

## GitHub Pages

1. Créez/ouvrez votre dépôt GitHub.
2. Envoyez les 3 fichiers à la racine du dépôt.
3. Allez dans `Settings` → `Pages`.
4. Dans `Build and deployment`, choisissez `Deploy from a branch`.
5. Sélectionnez `main` et `/ (root)`.
6. Cliquez sur `Save`.
7. Après quelques instants, GitHub donnera le lien du site.

Le site est pensé d'abord pour téléphone.
